What this can—and cannot—prove

A misplaced cover could indicate that the browser uses stale coordinates or ignores transforms. If the cover is part of the same rendered layer as the video, both may move together. CSS cannot directly resize native browser UI or edit the inside of a cross-origin YouTube iframe. No car-specific workaround has been verified here.

Embedding restrictions, YouTube error 153, network errors and autoplay blocks are separate from the car’s overlay. If playback fails, fix that first. The embedded clip contains no audio; YouTube has a separate sound button.
